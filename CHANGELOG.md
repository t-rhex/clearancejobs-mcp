# Changelog

## 0.1.0b1 · 2026-10-11

Initial beta:

- Four read-only MCP tools: search, saved jobs, applications and full descriptions.
- CLI access, compact list results, pagination and consistent job IDs.
- Nationwide search, Remote/Hybrid and a verified Florida state filter.
- Local macOS Keychain login, private atomic session storage, one bounded retry.
- File-locked session renewal shared by parallel requests.
- Portable MCP registration, wheel/source packages, clean-install checks and tests.

Known limitations: macOS-only supported beta, one account per OS user,
undocumented endpoints, manual intervention for MFA/verification, and no other
state filters. See README and BETA_NOTICE for service authorization requirements.
